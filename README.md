# Mission Analysis Portfolio

A technical portfolio exploring fundamental orbital mechanics, classical orbital transfers, and planetary flyby trajectories through analytical methods and computational simulations.

## Objectives

- Develop a strong foundation in orbital mechanics
- Implement and analyse common orbital transfer techniques
- Study planetary flyby and gravity-assist trajectories
- Develop computational tools for mission analysis
- Visualise and interpret orbital trajectories and mission parameters

## Projects

Projects will be added progressively.

## Topics

- Two-body orbital mechanics
- Keplerian orbits
- Hohmann transfers
- Bi-elliptic transfers
- Plane-change manoeuvres
- Interplanetary transfers
- Planetary flybys and gravity assists
